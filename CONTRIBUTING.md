# Contributing

Small, focused improvements are welcome. SwiftNote is a memo app: quick to open, calm to read, predictable to edit. Please open an issue before proposing cloud services, new runtimes, or a major expansion in scope.

Include reproduction steps for bugs. Use fictional notes when sharing screenshots; never include your data directory. For editing or persistence changes, add a regression case and run `./test.sh`. For UI changes, include actual narrow-window screenshots and verify the fixed light appearance under both system themes and an independent review of the affected interaction.

Do not claim a feature or performance result without a reproducible check. Contributions are accepted under the MIT license.
