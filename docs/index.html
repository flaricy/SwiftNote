实际应用界面 · 示例内容

01 — WRITE

写下去，不打断。

用熟悉的 Markdown 快捷输入，四级标题随手切换。一个 /，就能插入列表、待办、图片和表格。

## 周末的小计划↵
02 — SHAPE

工具靠近文字。

选中文字，就近完成排版。图片拖进来，按比例调整大小；表格直接填，待办点一下完成。

BIUS Aa
03 — REMEMBER

时间，需要时再看。

点击一行，修改时间轻轻出现在文字后面。行尾满了，就用小钟代替，悬停即刻查看。

给花浇水。09:41

手边，一个新念头。

菜单栏点一下，或在其他应用中按 ⌃⌥N，立即新建。
