# 发布文案

## 中文

SwiftNote · 随记，开源了。

念头一闪，随手记下。一个原生 macOS 备忘录：打开直接接着写，菜单栏一键新建，用 Markdown 快捷输入整理文字，也能插入图片、表格和待办。

我特别想把“什么时候改过”做得轻一点：点击一行，修改时间才出现在文字末尾；空间不足就留一个小钟，悬停即刻查看。

没有账户、订阅或云同步。Swift + AppKit，MIT 开源。

网站：https://flaricy.github.io/SwiftNote/
源码与下载：https://github.com/flaricy/SwiftNote

首发下载支持 Apple Silicon、macOS 14+。目前未经过 Apple 公证，首次安装请看仓库指南。

## English

Introducing SwiftNote — a small native macOS memo app, now open source.

A thought, a note. Open straight into your last memo, create one from the menu bar, and use Markdown shortcuts, images, tables, and checklists without a workspace getting in the way.

Edit times stay quiet: click a line to see its timestamp, or hover the little clock when space runs out.

Swift + AppKit. No accounts, subscriptions, or cloud sync. MIT licensed.

Website: https://flaricy.github.io/SwiftNote/
Source & download: https://github.com/flaricy/SwiftNote

The first download is for Apple Silicon, macOS 14+. Not Apple-notarized yet; see the installation guide before first launch.
