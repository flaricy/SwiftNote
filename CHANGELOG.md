# Changelog

## 1.0.0

First public release of SwiftNote · 随记.

- Native macOS memo editor, direct restore, menu-bar quick entry.
- Four heading levels, Markdown shortcuts, slash insertion and selection formatting.
- Checklists, images with proportional scaling, editable tables.
- On-demand line timestamps with immediate hover details.
- Local autosave, search, RTFD export, and isolated regression tests.
